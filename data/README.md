# Data Directory

This directory contains the synthetic dataset used for the Global Robotics Market Intelligence project.

## Folder Structure

- `raw/` — Original dataset, preserved without modifications.
- `processed/` — Cleaned and transformed datasets.
- `sample/` — Smaller sample datasets for testing and demonstration.

## Data Handling

The original dataset will remain unchanged. Data cleaning, transformation, and validation will be documented separately to maintain reproducibility.
